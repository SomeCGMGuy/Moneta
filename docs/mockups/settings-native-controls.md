# Moneta settings UX reference

This release keeps the existing Moneta visual language while applying three mobile-first interaction rules:

- Financial month start is selected through a horizontally scrollable chip control rather than a browser-style combobox.
- Category groups show a compact preview first. Larger lists provide search and an explicit expand/collapse action.
- Category icons are selected from a touch-friendly visual grid instead of being entered into a plain text field.

These interactions are the reference behavior for future settings changes until superseded by updated mockups or screenshots.
